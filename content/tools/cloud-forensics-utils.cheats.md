# cloud-forensics-utils

**Type:** Python Library
**Purpose:** Cloud forensics automation for AWS, Azure, GCP
**Platform:** Linux, macOS, Windows
**Tags:** #forensics #incident-response #aws #azure #gcp #automation

---

## Purpose

Automates cloud forensics tasks:
- Disk acquisition
- Memory capture
- Log collection
- Evidence preservation

Supports AWS, Azure, and GCP

---

## Installation

```bash
pip3 install libcloudforensics
```
