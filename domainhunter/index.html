domainhunter

A name is free, taken, or you do not know yet. Say which.

Availability checks that treat RDAP as the authority, expose disagreement between registrars, and never report a fallback as fact.

Usage

python run.py check example.com --price porkbun,godaddy
python run.py check --file examples/domains.txt --json -o out.jsonl
python run.py serp cloudbreachlabs
python run.py buy --file wanted.txt --contact contact.json --max-price 20 --total-budget 60 --expect-currency USD

Every write is a dry run until --commit. Purchases use a UUID idempotency key and a purchase ledger, so a lost response is safe to retry.

What it does

  • Ordered layers: DNS hint (informational), RDAP, IANA bootstrap, then a configured registrar fallback chain.
  • Conflicts recorded, not flattened: source disagreement, timeouts and single-source answers stay visible on the record.
  • Prices from four registrars for names RDAP says are free; first-year promo quotes suppressed where a real price exists.
  • Batch buying against a per-domain ceiling and a total budget, in your account's currency, with duplicate skipping.
  • SQLite cache and a purchase ledger; results de-duplicated.

Limits, stated so a pass is not over-read

UK verdicts are currently two registrars agreeing, not RDAP: Nominet's RDAP is unreachable from the host this was built on. A premium name comes back available with a large price, so filter on price as well as verdict. Someone else's rules still apply to the scraping sources. Two registrar sources that disagree leave the verdict inconclusive by design; that is the correct answer, not a gap.

Tests

110 tests, all offline, with URL-routed fake HTTP sessions. No network or credentials needed for a pass.
