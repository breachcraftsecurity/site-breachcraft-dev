What it is

Overview

Being able to hide or continually rotate the source IP address when making web calls can be difficult or expensive. A number of tools have existed for some time but they were either limited with the number of IP addresses, were expensive, or required deployment of lots of VPS's. FireProx leverages the AWS API Gateway to create pass-through proxies that rotate the source IP address with every request! Use FireProx to create a proxy URL that points to a destination server and then make web requests to the proxy URL which returns the destination server response!

Benefits

  • Rotates IP address with every request
  • Configure separate regions
  • All HTTP methods supported
  • All parameters and URI's are passed through
  • Create, delete, list, or update proxies
  • Spoof X-Forwarded-For source IP header by requesting with an X-My-X-Forwarded-For header

Installation

You can install and run with the following command:

$ git clone https://github.com/ustayready/fireprox
$ cd fireprox
~/fireprox$ virtualenv -p python3 .
~/fireprox$ source bin/activate
(fireprox) ~/fireprox$ pip install -r requirements.txt
(fireprox) ~/fireprox$ python fire.py

Note that Python 3.6 is required.

Building a Docker image: (Currently does not work on Docker for Windows, possibly due to line endings in entrypoint.sh.)

$ git clone https://github.com/ustayready/fireprox
$ cd fireprox
$ docker build -t fireprox .
$ docker run --rm -it fireprox -h

Quick Reference

# Create proxy URL
python3 fire.py --command create --url https://example.com

# List existing proxies
python3 fire.py --command list

# Delete proxy
python3 fire.py --command delete --api_id <api-id>

# Update proxy URL
python3 fire.py --command update --api_id <api-id> --url https://newurl.com

EVASION: Create API Gateway Proxy

# Create proxy for target URL
python3 fire.py --command create --url https://login.microsoftonline.com/

# Returns API Gateway URL:
# https://abc123.execute-api.us-east-1.amazonaws.com/fireprox/

# Use this URL instead of original
# Each request comes from different AWS IP

Common Use Cases

O365 Password Spraying

# Create proxy for Office 365
python3 fire.py --command create --url https://login.microsoftonline.com/

# Use with o365spray
o365spray --spray -U users.txt -p 'Password!' --proxy-url https://xyz.execute-api.us-east-1.amazonaws.com/fireprox/ --domain company.com

Bypassing IP-Based Rate Limiting

# Target blocks after N requests from same IP
# FireProx rotates source IP using AWS infrastructure

# Create proxy
python3 fire.py --command create --url https://target-api.com/

# Use proxy URL for requests
curl https://abc.execute-api.region.amazonaws.com/fireprox/endpoint

Management

# List all proxies
python3 fire.py --command list

# Delete proxy
python3 fire.py --command delete --api_id abc123

# Update target URL
python3 fire.py --command update --api_id abc123 --url https://new-target.com/

Pro Tips

💡 IP Rotation: Each request comes from different AWS IP range 💡 Rate Limit Bypass: Bypasses IP-based rate limiting 💡 AWS Costs: Minimal AWS API Gateway costs 💡 Regional: Can specify AWS region for proxy 💡 Integration: Works with o365spray, other tools via --proxy-url 💡 Clean Up: Delete proxies when done to avoid AWS charges

OPSEC

✅ Advantages: Legitimate AWS infrastructure, hard to block all AWS IPs ⚠️ Considerations: Requires AWS account (can be traced back if investigated)
