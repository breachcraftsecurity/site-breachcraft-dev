Purpose

Creates realistic AD environment with:

  • Thousands of users
  • Hundreds of groups
  • Complex ACLs
  • Nested groups
  • Service accounts
  • Kerberoastable users
  • AS-REP roastable users
  • Intentional vulnerabilities

Usage

# Run on Domain Controller
Invoke-BadBlood

# Populates AD with test data
# Use for:
# - BloodHound testing
# - Tool development
# - Red team training
# - Detection engineering
