What it is

Description

Scout Suite is an open source multi-cloud security-auditing tool, which enables security posture assessment of cloud environments. Using the APIs exposed by cloud providers, Scout Suite gathers configuration data for manual inspection and highlights risk areas. Rather than going through dozens of pages on the web consoles, Scout Suite presents a clear view of the attack surface automatically.

Scout Suite was designed by security consultants/auditors. It is meant to provide a point-in-time security-oriented view of the cloud account it was run in. Once the data has been gathered, all usage may be performed offline.

The project team can be contacted at <scoutsuite@nccgroup.com>.

Cloud Provider Support

The following cloud providers are currently supported:

  • Amazon Web Services
  • Microsoft Azure
  • Google Cloud Platform
  • Alibaba Cloud (alpha)
  • Oracle Cloud Infrastructure (alpha)
  • Kubernetes clusters on a cloud provider (alpha)
  • DigitalOcean Cloud (alpha)

Installation

# Install via pip
pip install scoutsuite

# Or from source
git clone https://github.com/nccgroup/ScoutSuite.git
cd ScoutSuite
pip install -r requirements.txt
python scout.py --help

Quick Reference

# Azure audit
scout azure --cli

# AWS audit
scout aws --profile default

# GCP audit
scout gcp --user-account

# Generate report
# Opens HTML report in browser automatically

Azure Auditing

# Using Azure CLI credentials
scout azure --cli

# Using service principal
scout azure --tenant <tenant-id> --client-id <client-id> --client-secret <secret>

# Specific subscription
scout azure --cli --subscription-ids <sub-id>

# All subscriptions
scout azure --cli --all-subscriptions

# Custom report directory
scout azure --cli --report-dir ./azure-audit-2024/

AWS Auditing

# Using default profile
scout aws

# Specific profile
scout aws --profile prod

# Specific regions
scout aws --regions us-east-1,us-west-2

# All regions
scout aws --all-regions

GCP Auditing

# Using user account
scout gcp --user-account

# Service account
scout gcp --service-account <path-to-key.json>

# Specific project
scout gcp --project-id <project-id>

# All projects
scout gcp --all-projects

What ScoutSuite Checks

Azure:

  • IAM configurations
  • Network security groups
  • Storage account settings
  • VM configurations
  • SQL database security
  • Key Vault access policies
  • Conditional Access policies
  • And more...

AWS:

  • IAM policies and users
  • S3 bucket permissions
  • EC2 security groups
  • RDS configurations
  • CloudTrail logging
  • And more...

GCP:

  • IAM bindings
  • GCS bucket permissions
  • Compute Engine settings
  • Cloud SQL configurations
  • And more...

Report Features

  • HTML dashboard
  • Risk ratings (danger, warning, info)
  • Detailed findings
  • Remediation guidance
  • Export to JSON
  • Customizable rule sets

Common Use Cases

Post-Compromise Assessment

# After gaining Azure access
az login
scout azure --cli --report-dir ./compromise-assessment/

# Review report for:
# - Weak configurations
# - Lateral movement opportunities
# - Privilege escalation paths
# - Additional access points

Security Audit

# Multi-cloud audit
scout azure --cli --report-dir ./audits/azure/
scout aws --profile client --report-dir ./audits/aws/
scout gcp --user-account --report-dir ./audits/gcp/

# Review all reports for security gaps
